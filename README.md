##A. Mobile Automation - Task 1

### Description

Automated test scenario using Appium with Java.

### Tech Stack

* Java
* Appium
* Selenium
* TestNG
* Maven

### Features Covered

* App launch
* Element interaction
* Assertions
* Test execution using TestNG

### How to Run

1. Open the project in IntelliJ
2. Install dependencies using Maven
3. Connect a real device or start emulator
4. Run the TestNG test file
